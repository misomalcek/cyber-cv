### Crystal RAG

- Crystal RAG is a desktop RAG app (Tauri, Rust, Three.js) with Qdrant and the embedding model shipped inside.
- Hybrid retrieval fuses vector, lexical and graph search with RRF (reciprocal rank fusion). Search runs locally, or through a local or cloud endpoint added in the app.

### Symferium

- Symferium is a local multi-model AI runtime for Apple Silicon: one Rust daemon picks the engine, watches the memory budget, and serves a browser UI plus an agent API.
- The catalog covers llama.cpp, MLX, mlx-vlm, whisper.cpp, ONNX and llamacpp-turboquant, with models pulled through the Hugging Face API.
- TurboQuant (turbo3) produced coherent text at about 10.5 tokens/s on this hardware.
- A governor selects the model, checks the cache and switches engines from the machine’s performance profile.

### Factorium — sovereign AI system, running daily on a Mac Mini M4, 24 GB (4.6 TFLOPS)
Private · demo on request

- Gemma-4 12B IT (Q5_K_M) and Gemma-4 26B (Q3) do the agentic work with no cloud inference, over 69 native tools and unified retrieval across Postgres, pgvector, Qdrant, Apache AGE and TimescaleDB.
- The system comprises 65,782 lines of TypeScript on 29 runtime dependencies; 12 modules written by hand in 2,004 lines instead of imported.
- Improved rule retrieval from 1 in 5 to 10 of 10 by storing rules as the situations that trigger them.
- Fused BM25 and vector search with reciprocal rank fusion (RRF), so the lexical and semantic ranks do not have to share one score.
- Organic memory (Phyto) returns the fact itself, about 30 tokens at p50 159 ms, roughly 70% less context than pointer-based RAG. 6,169 facts carry real timestamps.
- The knowledge graph holds 3,567 entities and 11,002 relations. The research corpus has 5,629 chunks in 187 files, each tagged primary, own, synthesis or OCR.
- Qdrant stores 78,413 embedding points in 18 collections, and the code graph covers 5 repositories.
- The longest unattended run was 120 turns, 120 tool calls and 67 minutes, without hitting a turn cap.
- Logged 477 tool calls with 0 reasoning failures. All 63 errors were environment or guard errors, and 75% recovered immediately.
- Fixed a 34× latency regression caused by one disabled prompt-cache flag, from 24.2 s to 1.0 s per task.
- Repaired the memory index after 77% of the corpus was silently truncated, from 1,050 to 15,232 chunks, and held 8/10 rank-1 recall through 14.5× growth.
- A reflex layer turns those 69 tools and 5 stores into one loop for the 12B model without prompt bloat. 41 tests cover it, and a dispatch that used to fail now succeeds in 1.5 s.

Details and screenshots: https://misomalcek.github.io/cyber-cv/production/factorium
